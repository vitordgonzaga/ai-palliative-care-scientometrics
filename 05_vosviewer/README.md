# VOSviewer files

Add here the files exported from VOSviewer 1.6.20 for the three networks reported in the article:

- country co-authorship: map and network files
- author co-authorship: map and network files
- KeyWords Plus co-occurrence: map and network files

Parameters used (program defaults, not modified): full counting; minimum of one document
per country and one occurrence per keyword; authors with at least four documents, ten
displayed; association strength normalisation; clustering resolution 1.00; documents with
more than 25 authors ignored (default), which excluded two documents from the author network.
